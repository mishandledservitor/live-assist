# Roadmap

Each row is one Spec Kit feature (`specs/NNN-short-name/`), taken through specify → plan → tasks → analyze → implement on its own worktree branch and merged by PR. Decisions behind this roadmap: `.specify/memory/design-decisions.md`. Principles: `.specify/memory/constitution.md`.

Status values: `idea` (not specified) → `planned` → `specified` → `planned-impl` → `in-progress` → `implemented` (merged to `main`) → `done` (real-meeting check recorded). Release 1.0.0 (2026-10-13) contains every feature marked implemented or done; release notes are in `CHANGELOG.md`.

## v1 — personal tool, Google Meet

| # | Feature | Depends on | Delivers | Status |
|---|---------|------------|----------|--------|
| 001 | Capture & live transcript | — | Project scaffold (WXT/React/TS, Vitest, Playwright, CI, CodeGraph). Settings with ElevenLabs key, user's name, key terms, consent-reminder toggle. Start/Stop from the side panel; tab audio and mic captured separately, mixed locally into one ElevenLabs realtime session (mic gated before mixing; constitution v1.1.0); live transcript in the panel, every line "Others" until 002's captions; auto language detection with per-meeting override; consent reminder; auto-reconnect; status indicators. Spikes: echo without headphones, mixed Greek/English. | done (signed off 2026-10-09) |
| 002 | Meet speaker names | 001 | Meet adapter: turn captions on and hide them, read caption speaker names, align them to transcript segments by time, fall back to "Others" with reason; name the user from Meet's "You" captions; follow Meet's mute state by silencing the mic before mixing; manual relabel (rename-all for named speakers, single-line override for "Others"). Settings → `Show Meet captions` (off by default) leaves Meet's captions visible instead of hiding them; the band Meet reserves for them is accepted (decision 61). | done (signed off 2026-10-09) — follow-ups: a ≥3-person trace; real-call check of `Show Meet captions` (2026-10-12, `specs/002-meet-speaker-names/manual-check.md`) |

Platform-free formatter in `src/core/export/` that 004 reuses; anchor/blob download, no new permission. | implemented, in 1.0.0 — file naming extended by 013 (decision 70); real-meeting check in `specs/007-download-transcript/manual-check.md` |

Stored with the meeting, deleted with it; sent only to the chat provider, never ElevenLabs (decisions 49–53). | implemented, in 1.0.0 — real-meeting steps 3, 4 and 7 still to run (`specs/008-meeting-context/manual-check.md`) |

| 012 | Past transcripts | 006, 007 | A Transcripts screen opened from one control in the main view's header (like Settings, decision 32): every stored meeting newest first with date, start time, duration, speaker names and an `Interrupted` marker; select one to read its transcript, read-only; per-meeting `Download transcript` (007's file) and `Delete transcript` (permanent, confirmed, with its chat and notes). After `Delete transcript` on the main view the panel opens this screen with what remains, and the main view is clean until the next Start (decision 64). The running meeting is listed but managed from the main view. No Ask, no rename, no multi-select. Taken out of 004 at the user's request 2026-10-12. (011 is reserved for the Zoom adapter.) | implemented, in 1.0.0 — most of the real check passed 2026-10-13; the running row and an interrupted meeting still to check (`specs/012-past-transcripts/manual-check.md`) |
| 013 | Captions download | 002, 007 (012 for the Transcripts screen) | On a Google Meet call, Meet's own captions (speaker name and text of each turn) are kept locally with the meeting as they arrive and deleted with it; the text never leaves the machine and is never given to Ask. `Download transcript` then saves one `Meeting — DD-MM-YYYY at HHhMM.zip` holding `… — Transcript.txt` and `… — Meet captions.txt` (the transcript's line format and display names); a meeting without captions downloads the plain `… — Transcript.txt`, one with captions only the plain `… — Meet captions.txt` (decisions 65–75). The reminder before Start on Meet and the delete confirmations say the captions are kept and deleted. Reverses "caption text is never read" (002 FR-004, research R5) for this purpose only; naming still uses names and timing (decision 63). Only meetings transcribed after it ships have captions. | implemented, in 1.0.0 — zip download and delete confirmation passed 2026-10-13; captions off/on, long-call and reload checks (O1–O7) still to run (`specs/013-captions-download/manual-check.md`) |
| 014 | Close transcript | 012 | After Stop the main view can be cleared without deleting the meeting (decisions 91, 92): `Close transcript` under the last line, between `Download transcript` and `Delete transcript`, clears it at once, and the next opening of the side panel after a meeting stopped (or was interrupted) opens it clean by itself. Clean is 012's state after a delete (decision 64), kept by the same remembered moment; the meeting stays on the Transcripts screen. A meeting stopped with the panel open stays (and can be asked about) until Close or the next opening; a running meeting is never cleared. Closing stops an answer still arriving. | in-progress — real-call steps in `specs/014-close-transcript/manual-check.md` |
| 016 | Merged download | 013 (012 for the Transcripts screen) | After the meeting, `Download transcript` saves one merged `.txt`: the realtime transcript's words with speakers from Meet's captions by word-level alignment at download time; unplaced words `Others`; passages the realtime transcript wrote twice (and the captions carry once) removed. The live panel is untouched; no audio kept, nothing re-transcribed. The 013 originals stay on the Transcripts screen's single-meeting view as `Download originals`; meetings without both records, and running meetings, download as before (decisions 93–100). | implemented — merged 2026-10-22; real-call steps in `specs/016-merged-download/manual-check.md` |

Order: 001 first (everything builds on it). Then 002, 003, 004 in that order — they all touch the side panel, so they run one after another rather than in parallel. v1 is done when 001–004 are merged and a real Meet call has been transcribed, labelled, questioned and exported end to end.
